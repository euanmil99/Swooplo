## 🚀 **Quick Start**

### **Prerequisites**
- Docker and Docker Compose
- Node.js 18+ (for development)
- 8GB+ RAM (16GB recommended)
- NVIDIA GPU (optional, for AI features)

### **1. Clone Repository**
```bash
git clone https://github.com/yourusername/social-affiliate-pro.git
cd social-affiliate-pro
```

### **2. Setup with LocalAI**
```bash
# Run the comprehensive setup script
chmod +x scripts/setup-localai.sh
./scripts/setup-localai.sh
```

### **3. Configure Environment**
```bash
# Edit environment variables
nano .env
```

### **4. Start Services**
```bash
# Start all services including LocalAI
docker-compose up -d
```

### **5. Access Application**
- **Main App**: http://localhost
- **LocalAI**: http://localhost:8080
- **Grafana**: http://localhost:3001 (admin/admin123)
- **API Docs**: http://localhost/api/docs
